Arbeitsweise

Coding-Agenten brauchen Leitplanken

Vorgabe

  • README und Backlog mit Akzeptanzkriterien
  • Fünf ADRs, acht Fachdokumente
  • Definition of Done

Regeln (AGENTS.md)

  • Modulgrenzen und Berechtigungen im Backend
  • Migrationen statt Schema-Änderung im Betrieb
  • Tests und Doku im selben Änderungspaket

Nachweis

  • Tests und Protokolle mit Commit-ID
  • Nicht Ausgeführtes wird benannt
  • Manuelle Prüfungen bestätigt der Auftraggeber

Der Agent liefert Code. Die Verantwortung für Anforderungen, Entscheidungen und Abnahme bleibt beim Menschen.

Hier kommt die Brücke zur Ausbildung: Das Projekt ist so dokumentiert, dass ein Agent (oder ein Azubi) es ohne mündliche Einweisung fortsetzen kann. Die Regel ‚keine vorgetäuschten Erfolgsmeldungen‘ steht ausdrücklich in AGENTS.md und wurde im Projekt auch gelebt: Was nicht ausgeführt werden konnte, steht so in den Protokollen.
