Technologien

Der Werkzeugkasten

Backend

  • Java 21, Spring Boot 4.1
  • Spring Security, Actuator
  • Maven mit Wrapper
  • springdoc-openapi (OpenAPI)
  • Flyway 12 für Migrationen

Frontend

  • React 19, React Router 7
  • TypeScript 6 (strict)
  • Vite 8 als Build
  • eigenes CSS, eigener fetch-Client
  • ESLint mit jsx-a11y

Betrieb und Tests

  • PostgreSQL 17, nginx 1.30
  • Docker Compose
  • JUnit 6, Testcontainers
  • Vitest, Testing Library
  • Playwright mit axe-core

Bewusst nicht dabei: UI-Bibliothek, globaler State-Manager, Microservices, GraphQL, Kubernetes.

Versionen sind in docs/TECHNOLOGIES.md dokumentiert und wurden tatsächlich gebaut und getestet. Zu jedem Eintrag soll ein Azubi ‚Was? Wofür? Warum?‘ in einem Satz sagen können. Der Verzicht auf UI-Bibliothek und State-Manager ist eine Entscheidung, kein Versäumnis: Jede Bibliothek müsste auf Tastatur, Screenreader, Wartbarkeit und Lizenz geprüft werden.
