Architektur

Der Weg einer Speicheranfrage

1

React

Formular speichern: PUT /api/v1/tasks/{id} mit Version, Session-Cookie und CSRF-Header

2

Spring Security

Session gültig? CSRF-Token passt? Sonst 401 oder 403

3

Anwendungsdienst

Darf genau dieser Benutzer genau diese Aufgabe ändern? Eingaben und Fachregeln prüfen

4

PostgreSQL

Änderung und Aktivitätseintrag in einer Transaktion, nur wenn die Version noch stimmt

5

Antwort

200 mit neuer Version, oder 409: Konflikt wird erklärt, der Entwurf bleibt erhalten

Anhand dieser Kette lässt sich fast jede Architekturfrage beantworten: Wo wird authentifiziert, wo autorisiert, wo liegt die Transaktion, wo entsteht der Konflikt. Frontend-Validierung hilft dem Benutzer, ersetzt aber nie die Backend-Prüfung.
