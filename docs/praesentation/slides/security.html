Sicherheit

Schutz liegt im Backend

Anmeldung

Serverseitige Session im Cookie (HttpOnly, SameSite=Lax), Ratenbegrenzung, Passwörter nur als Hash

CSRF-Schutz

Jede schreibende Anfrage braucht einen Token, den der Browser vorher abholt

Berechtigungen

Jede Datenoperation prüft Benutzer und Objekt im Backend; Fremdes liefert 404, nicht 403

Eingaben

Validierung im Backend, parametrisiertes SQL, React rendert Benutzertext nur als Text

Passwort-Wiederherstellung ist für dieses Demo-Projekt bewusst nicht umgesetzt. Ein Administrator sieht keine fremden Aufgaben.

Authentifizierung heißt: Wer bist du? Autorisierung: Darfst du genau das? Beides passiert im Backend. 404 statt 403 bei fremden Objekten, damit deren Existenz nicht verraten wird. Die Sicherheitsanforderungen stehen in docs/SECURITY.md.
