Nr.EntscheidungKernargument
ADR-001Modularer MonolithFachgrenzen im Code ohne den Betriebsaufwand von Microservices; lokale Transaktionen

ADRs sind kurze Entscheidungsprotokolle: Kontext, Entscheidung, Alternativen, Konsequenzen. Bestehende werden nicht umgeschrieben, sondern durch neue ersetzt. So kann man auch in einem Jahr noch erklären, warum etwas so gebaut ist.
