Deployment

Ein Befehl startet den ganzen Stack

web

nginx 1.30, Port 127.0.0.1:8080, liefert React, leitet /api

backend

Spring Boot, nur im Container-Netz, Healthcheck

db

PostgreSQL 17.11 mit benanntem Volume

cp .env.example .env # Passwort setzen

docker compose up -d --build --wait

curl --fail http://localhost:8080/actuator/health

Healthchecks erzwingen die Reihenfolge: erst gesunde Datenbank, dann Migrationen, dann Backend, dann web.

Java, Node und Maven müssen auf dem Host nicht installiert sein, die Builds laufen in Containern. Die Installation wurde auf einem frischen Checkout durchgespielt und protokolliert (dabei wurde ein falscher Healthcheck-Pfad in der Doku gefunden und korrigiert). Update, Backup und Restore sind für M4 geplant. Volumes sind kein Backup.
